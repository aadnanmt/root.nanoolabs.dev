## What is it?

Personal dotfiles for Niri (Wayland compositor) on Arch Linux. GitHub Dark Default theme, minimal, TUI-first. Fish + Starship, Kitty, Fuzzel, Waybar, LazyVim, all on `#58a6ff` accent over `#050505`.

## In my setup

Current daily driver. `install.sh --base|--all` deploys profiles (WM + shell + editor, or everything including the rice) with paru, and every alias/abbreviation is reachable from the shell via `cuyy` cheatsheet.
