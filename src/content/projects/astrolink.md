A simple link-in-bio page, rebuilt in Astro for faster builds and easier maintenance.

## Architecture

Static site generation. Single page with links. No backend, no database. Content defined in one config file.

## Tech Stack

- **Framework**: Astro
- **Styling**: Tailwind CSS
- **Deploy**: Vercel

## Quick Start

```bash
git clone https://github.com/aadnanmt/Astrolink.git
cd astrolink
bun install
bun run dev
```
