If you feel that typing `nmcli` is too long.... Did you know that nmcli has auto-completion?
I will demonstrate `nmcli` auto-completion. soo... no need create aliases or abbr for nmcli commands.

| Shortcut    | Full Command                              |
| ----------- | ----------------------------------------- |
| nmcli c s   | nmcli connection show                     |
| nmcli c u   | nmcli connection up "name-connection"     |
| nmcli c m   | nmcli connection modify "name-connection" |
| nmcli d w c | nmcli device wifi connect                 |
| nmcli d     | nmcli device                              |
| nmcli d w l | nmcli device wifi list                    |
| nmcli d w r | nmcli dev wifi rescan                     |

And much more, that still relate to the `device` and `connection` auto-completion. maybe I might continue explaining it in next content about nmcli, auto-completion and its features.
